# 智语·云枢 (SapientiaCloud EduPivot) 设计文档

## 一、产品定位

**智语·云枢** 是一个面向高等教育的云原生智慧教学平台，为教师和学生提供一站式的教学互动、课程管理、直播课堂和 AI 辅助教学解决方案。

### 核心价值

- **教学互动**：3D 虚拟教室、实时座位同步、课堂练习、弹幕互动
- **课程管理**：课程创建、章节编排、题库管理、作业布置、论坛讨论
- **直播课堂**：基于 WebRTC 的实时音视频直播，支持画中画模式
- **AI 教学助手**：智能问答、知识库管理、文档向量化、智能出题、语音合成

### 目标用户

| 角色 | 描述 | 核心需求 |
|------|------|----------|
| **学生** | 在校学生 | 课程学习、作业提交、课堂互动、AI 辅导 |
| **教师** | 授课教师 | 课程管理、作业批改、直播授课、数据分析 |
| **管理员** | 系统管理员 | 用户管理、权限配置、系统监控 |

## 三、技术架构

### 3.1 微服务拆分 (Redesign)

```
┌─────────────────┐
│   sc-frontend   │  Vue 3 + Naive UI + Three.js + LiveKit
│   (Nginx SPA)   │
└────────┬────────┘
         │
┌────────▼────────┐
│   sc-gateway    │  JWT 校验 + 服务发现路由 + 限流
│  :39080         │
└──┬────┬────┬───┘
   │    │    │
   ▼    ▼    ▼
┌────────┐ ┌────────────┐ ┌──────────┐ ┌──────────┐
│sc-auth │ │sc-notif.   │ │sc-course │ │sc-storage│
│:28081  │ │:28082      │ │:28084    │ │:28085    │
│认证    │ │通知        │ │课程      │ │存储      │
└────────┘ └────────────┘ └──────────┘ └──────────┘
   │           │              │            │
   └─────┬─────┴──────────────┴────────────┘
         ▼
┌──────────────────┐
│ PostgreSQL/Redis │
└──────────────────┘
```

### 3.2 安全架构

- **JWT**: RS256 非对称加密，auth 服务签发，其他服务通过 JWKS 验证
- **Access Token**: 30 分钟 TTL，仅含 userId + role
- **Refresh Token**: 7 天 TTL，Redis 存储，支持轮转
- **Token 黑名单**: 登出时 JTI 加入 Redis 黑名单
- **接口限流**: Redis 滑动窗口，作用于认证端点

## 五、设计风格

采用 **Academic Lumen** 设计系统：

- **字体**: Hanken Grotesk (标题/正文) + Inter (标签/辅助文字)
- **色彩**: 单色调为主，深炭黑 (#0D0D0D) 导航 + 柔灰 (#F0F2F5) 画布 + 纯白 (#FFFFFF) 卡片
- **圆角**: 大容器 24px，按钮/输入框 12px，头像圆形
- **阴影**: 卡片柔和阴影 (0px 4px 20px rgba(0,0,0,0.04))
- **布局**: 固定侧边栏 + 流动画布，12 列网格

## 六、重设计目标

本次重设计 (Redisign) 的核心目标：

1. **架构升级**: 从模块化单体重构为真正的微服务架构
2. **安全加固**: RS256 JWT + Refresh Token + Token 黑名单 + 接口限流
3. **前端重构**: 采用 Academic Lumen 设计系统，提升视觉品质
4. **功能完善**: 保持原有功能完整性，优化用户体验
